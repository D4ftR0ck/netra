# Netra ? VPN & Tor Exit IP Intelligence

A dated, queryable dataset of identifiable VPN/Tor exit IPs and related threat infrastructure,
for detection, log enrichment, and network policy use cases.

Among the exports, two lists are meant for direct use:

- **`denylist_asn.txt` / `denylist_cidr.txt`** ? networks to block.
- **`allowlist_asn.txt`** ? networks attested clean (positive-only signal).

> ?? Defensive / informational project. An entry here is a signal, never proof by itself.
